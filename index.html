Frequently Asked Questions

Got questions? We've got answers.

Is this verification system safe for bulk checking?
Yes, absolutely. Our backend uses a decentralized network of fast edge-workers that communicate directly with Gmail servers. There is no risk of email blacklisting or IP locking.
How does the Gmail Dot Trick work?
Google ignores dots (.) in usernames. Meaning, any email variation like m.y.n.a.m.e@gmail.com will automatically deliver to myname@gmail.com. This allows you to generate massive unique identifiers for registrations.
Do you provide Developer API integration?
Yes, we offer direct checking endpoints (like /check1) for developer keys. You can whitelist up to 3 domains or IPs and make programmatic calls from your Python, Node.js, PHP or cURL applications.
Which cryptocurrencies are supported for payment?
Through NOWPayments integration, we support all major cryptocurrencies including Bitcoin (BTC), Ethereum (ETH), Litecoin (LTC), USDT (TRC-20), Tron (TRX), and Ripple (XRP).

Gmail Checker Guide

How to use the Bulk Gmail Checker tool

Purpose: Verify large lists of Gmail addresses to see if they are active, disabled, or unregistered.

How to Use:

  1. Navigate to the Apps > Gmail Checker menu.
  2. Paste your email list into the input box (supports thousands of lines instantly without lag).
  3. Select your desired speed/accuracy mode (e.g., Fast Check vs Deep Check).
  4. Click Start Checking.
  5. The results will populate in real-time using virtual scrolling. You can filter results by Live, Disabled, or Unregistered, and easily copy the filtered results to your clipboard.

Gmail Dot Tricks

Learn about Gmail Dot Tricks variation generator

Purpose: Generate unique email aliases by inserting dots into your existing Gmail address. Google ignores dots in usernames, meaning all generated variations will route to your single main inbox.

How to Use:

  1. Navigate to the Apps > Dot Trick menu.
  2. Enter your base Gmail address (e.g., myname@gmail.com).
  3. Click Generate.
  4. The system will use a Fisher-Yates chunking algorithm via Web Workers to instantly output all possible dot permutations without crashing your browser.

Name Combiner

Mix and match names to generate usernames

Purpose: Mix and match lists of first names, last names, and numbers to generate massive lists of potential usernames or email prefixes.

How to Use:

  1. Navigate to the Apps > Name Combiner menu.
  2. Input your lists in the provided columns (Column A for First Names, Column B for Last Names, etc.).
  3. Choose your separator (dot, underscore, none).
  4. Click Combine. The engine will cross-reference and permute the lists, outputting the results into a clean, copyable format.

async function validateEmails(emails) {
	try {
		const response = await fetch(`${SERVER_URL}/check1`, {
			method: 'POST',
			headers: {
				'Authorization': `Bearer ${API_KEY}`,
				'Content-Type': 'application/json'
			},
			body: JSON.stringify({
				mail: emails
			})
		});
		
		if (!response.ok) {
			throw new Error(`HTTP ${response.status}: ${response.statusText}`);
		}
		
		const data = await response.json();
		return data;
	} catch (error) {
		console.error('Validation error:', error);
		throw error;
	}
}

$api_key = 'your_api_key_here';
$server_url = 'https://gmail-checker.blacksoftchild.workers.dev';

// Check Google (Gmail) Account Status
function validateEmails($emails) {
	global $api_key, $server_url;
	$data = json_encode(['mail' => $emails]);
		
	$ch = curl_init("$server_url/check1");
	curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
	curl_setopt($ch, CURLOPT_POST, true);
	curl_setopt($ch, CURLOPT_POSTFIELDS, $data);
	curl_setopt($ch, CURLOPT_HTTPHEADER, [
		"Authorization: Bearer $api_key",
		"Content-Type: application/json"
	]);
		
	$response = curl_exec($ch);
	$http_code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
	curl_close($ch);
		
	if ($http_code !== 200) {
		throw new Exception("HTTP $http_code: $response");
	}
		
	return json_decode($response, true);
}

// Usage example
$emails = ['test1@gmail.com', 'test2@gmail.com', 'test3@gmail.com'];
try {
	$results = validateEmails($emails);
	echo 'Validation results: ' . print_r($results, true);
} catch (Exception $e) {
	echo 'Error: ' . $e->getMessage();
}
